# Network+ Practice Lab

A browser-based CompTIA Network+ N10-007 practice quiz built as a static site.

## Features

- Study mode with instant answer feedback
- Exam mode
- Random or sequential question order
- 10, 25, 50, 100, or full-bank sessions
- Multi-select question support
- Missed-question practice pool
- Bookmarks
- Browser-local progress using `localStorage`
- Source page references for questions

## Hosting

This repository is structured for GitHub Pages.
